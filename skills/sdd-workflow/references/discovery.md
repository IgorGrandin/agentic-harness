# Discovery workflow

Discovery is read-only unless the user also requests changes.

1. State the question and what evidence would answer it.
2. Inspect the smallest likely repository surface, expanding only when evidence requires it.
3. Distinguish facts, inferences, unknowns, and contradictions.
4. Produce a concise findings artifact or inline report with evidence links.
5. Recommend a next step and model lane, but do not silently transition into implementation.
