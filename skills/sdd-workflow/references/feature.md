# Feature workflow

1. Confirm user outcome, boundaries, constraints, and explicit non-goals.
2. Inspect existing extension points and conventions before selecting a design.
3. Compare alternatives only where the choice materially affects cost, compatibility, or maintainability.
4. Define acceptance criteria and verification before implementation.
5. When authorized, implement in reviewable slices that preserve the active spec.
6. Verify end-to-end behavior and relevant failure paths.

Pause for a user decision when repository reality requires a materially different product outcome.
