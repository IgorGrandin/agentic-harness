# Global memory bank

Read this file first. Load another file only when its description matches the current task.

| File | Load when | Contains |
|---|---|---|
| `preferences.md` | A stable user preference could change how the work is performed or presented | Confirmed cross-project working preferences |
| `decisions.md` | A cross-project tool or workflow choice is being reconsidered | Durable decisions, rationale, and supersession links |
| `lessons.md` | A known recurring failure mode may apply | Evidence-backed reusable lessons |

Repository architecture, commands, active task state, and project decisions do not belong here. Store them in the repository's own Markdown source of truth.

## Write policy

Add an entry only when it is durable, useful across repositories, and supported by an explicit user statement or verified outcome. Date decision and lesson entries. Update or supersede stale entries instead of accumulating contradictions.
